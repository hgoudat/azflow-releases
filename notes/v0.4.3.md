## What's new

GitHub works on Windows without administrator rights.

- **GitHub CLI without an administrator prompt.** On Windows, setup installs the GitHub CLI into your user profile (`winget install --id GitHub.cli --scope user`).
- **Found right after you install it.** Azflow finds the GitHub CLI and Git as soon as they are installed, without restarting the app, and the sign-in terminal can use them at once.
- **Clear message without Git.** Cloning on Windows without Git says so and shows a command that installs it without administrator rights.
- **Setup terminal.** The install terminal no longer repeats "Terminal session is not running" after the command finishes.
- **Updates.** Settings → Updates says "You're using the latest version." when no update is available, instead of "Couldn't determine the latest desktop release."
