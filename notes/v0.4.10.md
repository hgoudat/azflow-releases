## What's new

Azflow AI inside VS Code, and the dark Azflow AI icon everywhere.

- **Azflow AI for VS Code.** Install [Azflow AI from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=azflowai.azflow-ai) to use the whole app beside Chat, or in an editor tab. With this version of the app:
  - files the app opens go to your VS Code window, at the line;
  - **Ask About Selection** (Cmd+Alt+A / Ctrl+Alt+A) starts a thread with your selected code in the message box;
  - the app follows VS Code's light or dark theme while its own theme is set to System.
- **Dark app icon.** The app's favicons and install icons now use the dark Azflow AI icon, the same as the Dock.
- **Windows.** The mouse wheel scrolls Settings → Plugins while the pointer is over a plugin card.
- **Security.** Other websites can no longer show the app running on your computer inside their own pages.
