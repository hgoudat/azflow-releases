## What's new

Security fixes and updated dependencies.

- **More approvals in Ask mode.** The Azflow agent now asks before it uses an MCP tool or reads files outside the project. Choosing **Always** applies only to that tool, or to outside reads.
- **Safer file opening on Windows.** Files opened from a thread are marked as downloaded from the internet, so Windows SmartScreen and Office Protected View still check them. More file types that can run, install or mount, such as disk images, are blocked. Links to network shares are refused.
- **Workspace transfers.** Links that could point outside the workspace are no longer copied.
- **Updated libraries.** tokio and the TLS certificate libraries are updated.
