## What's new

See what your agents are doing as a live map, and get a suggested next message.

- **Agent Graph.** A live map of your projects, threads, turns, tool calls and subagents that updates while agents work. Open **Agent Graph** in the sidebar, click the graph button in a thread's header, or run `azflow-cli agent-graph` in a terminal.
- **Suggested next message.** After an agent replies, the message you're likely to send next appears as faint text in the empty message box. Press **Tab** to turn it into a draft you can edit. Nothing is sent for you.
- **What suggestions cost.** Each suggestion uses one request on the thread's agent. Threads on Azflow Cloud agents don't get suggestions. You can pick a separate model in Settings → Plugins → Composer Predictions, or turn either feature off on the Plugins page.

Agent Graph and Composer Predictions are based on MIT-licensed plugins by Nathan Colgate and MacHatter1.
