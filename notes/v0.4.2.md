## What's new

Azflow AI now shows only the agents that are set up on your computer.

- **Only agents you can use.** New threads offer an agent once it is installed and signed in on this computer. LM Studio appears while its server is running, and Azflow AI once it is turned on. Sessions that refresh themselves (Codex, Claude Code) stay listed.
- **A clearer setup.** The Agents step lists your ready agents first, then the installed ones that still need a sign-in. With none installed, it offers Codex or Claude Code, or Azflow AI on the next step.
- **opencode on the usage panel.** opencode running on other providers (OpenRouter, LM Studio and others) no longer asks you to run `opencode auth login`.
- **Crash reports.** With usage data sharing on (Settings → Advanced), the app sends crash reports, without account details, computer name or IP address.
