## What's new

Running several agents at once no longer slows your computer to a crawl.

- **CPU and memory limits.** New turns wait while your computer is at or above 80% CPU or memory, and start as soon as it frees up. The thread says why it is waiting, for example "CPU 92% of 80% limit", and **Send now** still starts it at once. One turn can always run, so a busy computer slows Azflow AI down instead of stopping it.
- **Memory comes back when it's tight.** When memory reaches 80%, agents that have been idle for a few minutes are paused to free it. They pick up again on your next message.
- **A more responsive app.** Agents, and the tools and MCP servers they run, use lower priority, so the app stays responsive while they work.
- **See and change the limits.** Settings → Concurrency shows live CPU, memory and agent use, and lets you change or turn off each limit. `azflow-cli concurrency-limit resources` and `azflow-cli concurrency-limit agents` do the same from a terminal.
