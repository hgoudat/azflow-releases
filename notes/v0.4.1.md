## What's new

A Windows release.

- **Projects on Windows.** Add any folder as a project, including `C:\` paths, with the Windows folder picker.
- **No more crash on quit.** Closing the app on Windows no longer reports a crash.
- **Windows paths everywhere.** Diffs of files in folders, branch updates, skill installs and Cloud starts with local skills now work on Windows.
- **Tools and the command line.** MCP servers and tools started through `npx`, `uvx` and similar run on Windows, and `azflow-cli terminal attach` works there.
- **Installs on Windows.** Cursor installs from the app, and Cancel works during an install.
- **Command line fixes on every platform.** `project paths`, `project content`, `project branches` and `thread log` work again.
