## What's new

GitHub Copilot and Kiro join the agents you can use on your computer.

- **GitHub Copilot.** Install the [Copilot CLI](https://github.com/github/copilot-cli) and run `copilot login`. GitHub Copilot then appears in Setup and the agent picker, with the models your Copilot plan includes.
- **Kiro.** Install the [Kiro CLI](https://kiro.dev/docs/getting-started/installation/) and run `kiro-cli login`. Kiro then appears in Setup and the agent picker, with its models.
- **Only what's set up.** As with the other agents, Setup and the pickers list only the agents installed on your computer. An agent that is installed but signed out shows under **Sign in to use**, with the command to sign in.
- **Skills.** Each agent's own skills folders are picked up, for example `.github/skills` for Copilot and `.kiro/skills` for Kiro.
- **Model list.** A model an agent lists twice now shows once.
