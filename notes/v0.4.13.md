## What's new

Composer menus behave consistently, and the VS Code extension updates from the Marketplace.

- **Composer menus.** The Model, Effort and Access menus under the message box all open upward. They no longer switch between opening up and down depending on where the window is on screen.
- **VS Code extension 0.1.3.** The Azflow AI extension for VS Code is now published to the Visual Studio Marketplace with each release, so VS Code keeps it up to date.
