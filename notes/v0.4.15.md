## What's new

Start a terminal that runs a command, from the command line.

- **`bb terminal create -- <command>`.** This now works for terminals on your computer. It used to stop with "Request does not match the terminal schema" on Mac, Windows and Linux.
- **Arguments and exit codes.** Each argument reaches the program exactly as given, including spaces and quotes, and the terminal reports the program's own exit code. This holds in PowerShell, cmd.exe and POSIX shells.
