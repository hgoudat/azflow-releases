## What's new

Install more coding agents from Setup.

- **Install another agent.** Setup's Agents step has a new optional section that lists every coding agent not on your computer. It starts collapsed when you already have an agent set up, so it stays out of the way. You can skip it, and **Finish later** works as before.
- **One-click installs.** Codex, Claude Code, Pi, Cursor, GitHub Copilot and Kiro install from there with **Install**, then ask you to sign in. Agents without an installer link to their own install instructions.
- **No restart needed.** An agent installed into a folder the app wasn't watching yet, such as `~/.local/bin` on a Mac, is found right away.
- **Pickers unchanged.** The thread pickers still list only the agents that are installed and signed in.
