## What's new

Install more coding agents from Setup, and Windows fixes.

- **Install another agent.** Setup's Agents step has a new optional section that lists every coding agent not on your computer. It starts collapsed when you already have an agent set up, so it stays out of the way. You can skip it, and **Finish later** works as before.
- **One-click installs.** Codex, Claude Code, Pi, Cursor, GitHub Copilot and Kiro install from there with **Install**, then ask you to sign in. Agents without an installer link to their own install instructions. On Windows, Kiro links to its installer.
- **No restart needed.** An agent you just installed is found right away, including one installed into `~/.local/bin` on a Mac or added to your PATH on Windows.
- **Windows installs.** Installs no longer stop at a hidden prompt (for example, winget's source agreement), and the install log shows the installer's output.
- **Windows startup.** The app now starts on PCs without the Visual C++ Redistributable.
- **Icons.** Agent icons are black and white everywhere.
- **Pickers unchanged.** The thread pickers still list only the agents that are installed and signed in.
