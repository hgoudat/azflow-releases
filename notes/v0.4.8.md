## What's new

File links in agent replies now open the file every time.

- **Links only for files that exist.** When an agent's reply mentions a file in inline code, it becomes a link only if that file exists on your computer. Names like a file type (`.vsix`) or a file the agent only talked about stay plain text, instead of opening a "File not found" preview with a "Failed to open file locally" error.
- **Real files work as before.** Links to files that exist, including `file:line` references, open in the preview at that line.
